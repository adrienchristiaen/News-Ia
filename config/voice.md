# Ton de la chaîne (à compléter par toi)

Ce fichier est injecté dans le prompt qui rédige le brouillon du script. **Plus il est précis, plus le brouillon sonnera comme toi.** Remplace le contenu ci-dessous par ta vraie façon de parler.

## Ce que je veux
- Tutoiement, phrases courtes, un peu d'ironie, jamais de jargon sans explication.
- Je distingue toujours **ce qui est annoncé** de **ce qui est réellement disponible / prouvé**.
- Pas de hype : si une « révolution » n'est qu'une mise à jour, je le dis.
- Une idée par séquence, un chiffre ou un fait concret par séquence.

## Ce que je ne veux pas
- « Incroyable », « révolutionnaire », « tout change », points d'exclamation en rafale.
- Affirmer un fait qui n'est pas dans les sources fournies.

## Structure d'un épisode (60 à 90 s, ~150 mots/min de voix)
1. Accroche (5-8 s) : le fait le plus marquant de la semaine.
2. 3 à 5 séquences (10-15 s chacune) : fait → pourquoi ça compte → bémol.
3. Clôture (5 s) : une question ou une phrase mémorable.
